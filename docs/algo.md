## 1️⃣ 诊断计数器设计哲学

```python
stats_counter = {
    'total': 0,           # 总扫描窗口数
    'monotonic_fail': 0,  # 阶段 1: 电流非单调 → 跳过
    'r2_pre_fail': 0,     # 阶段 2: Cheung I 的 R² < 0.8 → 跳过
    'constraint_fail': 0, # 阶段 3: n 或 R² 超出约束 → 跳过
    'r2_final_fail': 0,   # 阶段 4: Cheung II 的 R² 不足 → 跳过
    'rs_mismatch': 0,     # 阶段 5: Rs 不一致 → 跳过
    'success': 0          # ✅ 通过所有阶段
}
```

### 🎯 设计理念：**5 阶段漏斗过滤**

```
                    总窗口数 (total)
                         │
                         ▼
              ┌──────────────────────┐
              │ 阶段 1: 单调性检查    │ ← 物理基础：正向偏压电流应单调增长
              │ monotonic_fail       │
              └──────────┬───────────┘
                         │ 通过
                         ▼
              ┌──────────────────────┐
              │ 阶段 2: Cheung I 预筛 │ ← 快速排除：R² < 0.8 直接跳过
              │ r2_pre_fail          │
              └──────────┬───────────┘
                         │ 通过
                         ▼
              ┌──────────────────────┐
              │ 阶段 3: 物理约束检查  │ ← 核心：n 范围、R²阈值
              │ constraint_fail      │
              └──────────┬───────────┘
                         │ 通过
                         ▼
              ┌──────────────────────┐
              │ 阶段 4: Cheung II 验证│ ← 双重验证：H(I) 线性度
              │ r2_final_fail        │
              └──────────┬───────────┘
                         │ 通过
                         ▼
              ┌──────────────────────┐
              │ 阶段 5: Rs 一致性检查 │ ← 自洽性：两种方法提取的 Rs 应接近
              │ rs_mismatch          │
              └──────────┬───────────┘
                         │ 通过
                         ▼
                    ✅ success!
```

### 💡 为什么需要 5 阶段？

| 阶段 | 目的 | 计算成本 | 排除比例 |
|-----|------|---------|---------|
| 1. 单调性 | 物理合理性 | 低 | ~30% |
| 2. R²预筛 | 快速排除 | 低 | ~20% |
| 3. 约束检查 | 核心物理约束 | 中 | ~30% |
| 4. Cheung II | 双重验证 | 中 | ~10% |
| 5. Rs 一致性 | 自洽性检查 | 低 | ~5% |

**优势**：
- ✅ **早期排除**：低成本检查先执行，避免浪费计算
- ✅ **诊断清晰**：失败时知道哪个阶段出问题
- ✅ **物理严谨**：多重验证确保结果可靠

```python
window = self.config.window_size  # 例如：25 点

for start_idx in range(0, len(bias_proc) - window + 1, step):

    I_win = I_proc[start_idx:end_idx]

    y_win = dV_dlnI[start_idx:end_idx]
    
    # ... 5 阶段检查 ...
    
    if 所有检查通过:
        stats_counter['success'] += 1  # ← 通过才计数
```

### 📊 可视化滑动过程

```
假设：bias_proc 长度 = 100 点，window=25, step=3

窗口 1: [0:25]   → 检查 → 失败 → monotonic_fail += 1
窗口 2: [3:28]   → 检查 → 失败 → r2_pre_fail += 1
窗口 3: [6:31]   → 检查 → 成功 → success += 1  ⭐
窗口 4: [9:34]   → 检查 → 失败 → constraint_fail += 1
...
窗口 32: [93:118] → 检查 → 失败 → rs_mismatch += 1

总窗口数 = (100 - 25) // 3 + 1 = 26 个窗口
```

### 🔍 为什么 `total` 增加但 `success` 可能为 0？

```
total = 72   ← 扫描了 72 个窗口
success = 0  ← 没有一个通过全部 5 阶段检查

原因：
• 可能所有窗口的 n 都超出约束 (n > 5.0)
• 或 Cheung II 的 R² 都不足
• 或 Rs 一致性检查失败
```

**这就是「多阶段筛选失败。通过：0/72」的含义**

## 3️⃣ `_compute_score()` 的作用

```python
def _compute_score(self, r2: float, I_range: Tuple[float, float], 
                   residuals: np.ndarray) -> float:
    """
    综合评分：选择「最佳」窗口
    
    评分组成:
    - R² 权重 60%: 线性度最重要
    - 电流跨度 30%: 覆盖范围越宽越好
    - 平滑度 10%: 残差越小越好
    """
    score_r2 = r2 * 0.6
    
    log_span = np.log10(I_range[1] / (I_range[0] + 1e-20))
    score_range = min(log_span / 2.0, 1.0) * 0.3
    
    smoothness = 1.0 / (1.0 + np.std(residuals) * 1e3)
    score_smooth = smoothness * 0.1
    
    return score_r2 + score_range + score_smooth
```

### 🎯 为什么需要评分？

**情境**：多个窗口都通过 5 阶段检查，选哪个？

```
窗口 A: R²=0.96, 电流跨度=1 decade, 残差小 → score=0.85
窗口 B: R²=0.92, 电流跨度=2 decades, 残差中 → score=0.82
窗口 C: R²=0.98, 电流跨度=0.5 decade, 残差大 → score=0.79

选择：窗口 A (最高分)
```

### 📐 评分公式详解

```python
# 1. R² 分数 (60%)
score_r2 = r2 * 0.6
# R²=0.95 → 0.57 分

# 2. 电流跨度分数 (30%)
log_span = np.log10(I_max / I_min)  # 例如：2 decades
score_range = min(log_span / 2.0, 1.0) * 0.3
# 跨度 2 decades → 1.0 * 0.3 = 0.3 分
# 跨度 1 decade → 0.5 * 0.3 = 0.15 分

# 3. 平滑度分数 (10%)
smoothness = 1.0 / (1.0 + std(residuals) * 1000)
score_smooth = smoothness * 0.1
# 残差小 → 接近 0.1 分
# 残差大 → 接近 0 分

# 总分 = 0.57 + 0.3 + 0.1 = 0.97 (满分)
```

### 💡 物理意义

| 评分项 | 物理意义 | 为什么重要 |
|-------|---------|-----------|
| **R² (60%)** | 线性度 | Cheung 方法核心假设：dV/d(lnI) vs I 应线性 |
| **电流跨度 (30%)** | 数据覆盖范围 | 跨度太窄 → 结果对噪声敏感 |
| **平滑度 (10%)** | 拟合质量 | 残差大 → 可能有未建模物理效应 |

## 5️⃣ 为什么您的 L6 严格约束结果更好？

| 约束 | 宽松 (n_max=15) | 严格 (n_max=5) | 影响 |
|-----|----------------|---------------|------|
| **成功率** | 100% | 50% | 严格排除不可靠数据 |
| **n 平均值** | 9.43 | 2.36 | 严格约束排除高 n 异常值 |
| **ΦB 范围** | 0.08-0.14 eV | 0.37 eV | 严格约束结果更集中 |
| **物理意义** | 存疑 (n~10) | 合理 (n~2-3) | 严格约束更符合热电子发射模型 |

**关键洞察**：
> **高成功率 ≠ 好结果**
> 
> 宽松约束让所有像素都「拟合成功」，但 n~10 说明可能不是纯热电子发射主导
> 
> 严格约束虽然成功率 50%，但通过的像素结果物理意义明确

|-----|------|-----------|
| **5 阶段计数器** | 诊断失败原因 | 知道问题出在哪，方便调整 |
